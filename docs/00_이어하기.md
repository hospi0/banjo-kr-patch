## 카주이 구조
- 에셋 색인표 ROM 0x5E90: `[BE32 n=0xE24][ffffffff]` + n×`{BE32 off, u16 comp, u16 type}`, 데이터 기준 0xCFB8, 에셋 끝 0xD87C98.
- 압축: `11 72` + BE32 크기 + raw deflate.
- 대사 블록: `[nlang=1][u16le off=3]` → 섹션 2개(아래칸/위칸), 각 `[count]` + `{cmd, len, data}`.
  cmd ≥0x80 = 화자 초상화 + 문장(NUL 포함 길이), 04 = 끝, 06/07/08 = 대기·분기 등 제어.
- 퀴즈 블록: `[1][2B][u16le off=5]` → `[count]` + `{cmd, len, data}`, 0x80 = 문제 줄, 0x81~0x83 = 보기.
- 대사 글꼴 = 에셋 0x6EB: 글리프 75개(0x21~0x6B), 높이 13, I8, 글리프마다 `{s16 폭, s16 13, u16 텍스처폭(8/16), u16 13}` + 8정렬 + 픽셀.
  빈 칸 `#$%&*+<=>@`는 'A'로 채워져 있음. 0x5B~ 는 유럽판 악센트(Ö Ü ß À …). 그림: `work/bk_font_6EB.png`.
- UI 문자열: 압축 코어 데이터 ROM 0xF9FA9E(풀면 91,648B) — 파일 선택·일시정지 메뉴·지역 이름·엔딩 출연진 119개.
  메뉴용 두 번째 글꼴의 글자 순서표 `0123456789:ABCDEFGHIJKLMNOPQRSTUVWXYZ@%?()<>".;-!/'` 도 여기 있음.
- 코드 블록: 0xF1C830(core1) / 0xF3ADB0(core2) 등 0xF1C830~0xFDDA9E 에 code+data 쌍 16개. 에셋 뒤 0xD87C98~0xF1C830 은 미조사.
- 롬 끝 빈 곳 137KB.
